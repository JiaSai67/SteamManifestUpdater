# SteamManifestUpdater

A PySide6-based application for managing and updating Steam Manifests, integrating with Online-Fix patches seamlessly.

## Project Structure

- `src/` - Core application code
- `tests/` - Test scripts
- `scripts/` - Auxiliary development scripts
- `assets/` - Icons and static resources
- `logs/` - Execution logs

## Usage

Run `start_gui.bat` to launch the application.

See `requirements.txt`.
